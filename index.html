Drills

Pause intake to simulate a network partition. The engine holds its offsets; switching off replays the backlog. Nothing is lost by design. Paste an operator JWT first (mint one with loader -token).

Kill-9 drill runs outside the browser: stop the engine process, restart it, then look a saga up again. States return from the write-ahead log. Scripted in scripts/recovery.ps1.

Stop the engine process (kill -9 / Stop-Process -Force), start it again with the same environment, and compare the settlement report before and after. scripts/recovery.ps1 does this and fails if one byte differs.
